Рабочая папка — это та папка, которую создают для какой-то задачи: проекта, работы, личных заметок. То есть просто удобное место для хранения файлов в процессе дела.
Индекс в Git — это промежуточная область (staging area — «область подготовки» или cache — «кэш»), которая служит буфером между рабочей директорией (файлами, для работы в редакторе) и хранилищем объектов репозитория.
Коммит - это точка сохранения проекта, которая фиксирует, какие изменения были внесены, кто их автор и когда.
Различия между Git и GitHub: Git — инструмент для работы с версиями кода на вашем компьютере, а GitHub — это веб-сервис, который помогает хранить эти версии в облаке и удобно сотрудничать с другими разработчиками
Использованные команды:
Команда git status показывает текущее состояние репозитория: что изменилось с момента последнего коммита и что готово к фиксации.
Команда git diff в системе контроля версий Git сравнивает два состояния репозитория и показывает различия между ними. Она позволяет увидеть, какие строки в файлах были добавлены, удалены или изменены.
Команда git diff --staged (её ещё можно встретить как git diff --cached) показывает разницу между индексом (staging area) и последним коммитом (HEAD).
